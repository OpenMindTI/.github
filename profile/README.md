## 🧠 Quiénes somos

Somos una consultora argentina de tecnología. Diseñamos, implementamos y operamos soluciones de TI para pymes y organizaciones que necesitan ordenar su infraestructura, automatizar procesos y dar un soporte de calidad a sus usuarios.

## 🛠️ Qué hacemos

| | |
|---|---|
| 🎫 **Mesa de ayuda e ITSM** | Implementación y personalización de **GLPI**: tickets, SLA, reportes e inventario de activos con **GLPI-Agent**. |
| 🖥️ **Infraestructura** | Servidores propios y en la nube, bases de datos **MariaDB** y acceso seguro con **Cloudflare Tunnel**. |
| ⚙️ **Automatización** | Scripts y flujos para tareas repetitivas, despliegues y monitoreo. |
| 🌐 **Presencia web** | Sitios institucionales y comercio electrónico sobre **WordPress**. |
| 🧭 **Consultoría** | Relevamiento, diagnóstico y hoja de ruta de transformación digital. |
